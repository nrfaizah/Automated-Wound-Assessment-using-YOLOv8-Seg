# Automated Wound Assessment Using YOLOv8-Seg

This repository contains the code developed for my Master's research project on automated wound assessment using YOLOv8-Seg.

The system performs:
- Wound detection
- Severity classification (Normal, Mild, Severe)
- Wound segmentation
- Wound size estimation (cm²)

## Models
The project evaluates the original YOLOv8-Seg and modified backbone architectures:
- MobileNetV3-Small
- EfficientNetV2-S
- ShuffleNetV2

## Tools
Python • YOLOv8 • PyTorch • OpenCV • Roboflow • Google Colab • Raspberry Pi

This project is for academic and research purposes.
